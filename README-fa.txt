اپ اندروید سئو (3eo.ir) برای کافه‌بازار و مایکت
================================================
این پروژه سایت را داخل یک اپ سبک باز می‌کند (با آیکون، کشیدن برای تازه‌سازی، صفحه‌ی «اینترنت قطع است»، اشتراک‌گذاری، دانلود فایل). داخل اپ هیچ چیزی برای خرید دیده نمی‌شود (قیمت‌ها، خرید اعتبار و درگاه پرداخت). کاربری که قبلاً در سایت اعتبار خریده همان اعتبار را در اپ مصرف می‌کند.

پیش از ساخت اپ: نسخه‌ی ۰٫۳۵٫۰ سایت را حتماً روی هاست آپدیت کنید (حالت اپ در آن است).

ساخت فایل APK با GitHub (بدون نصب هیچ برنامه‌ای)
-----------------------------------------------
۱) در github.com با حساب خودتان وارد شوید و یک مخزن جدید بسازید. نوع آن حتماً Private باشد (چون کلید امضای اپ در خروجی ساخت قرار می‌گیرد).
۲) داخل مخزن: Add file > Upload files. همه‌ی فایل‌ها و پوشه‌های همین zip (بعد از Extract) را بکشید و Commit کنید.
   اگر پوشه‌ی مخفی «.github» بالا نیامد: Add file > Create new file، نام را دقیقاً این بنویسید:
        .github/workflows/build-android.yml
   و محتوای فایل build-android.yml.txt را داخلش کپی کنید.
۳) تب Actions > «Build Android APK» > Run workflow > Run workflow. حدود ۵ تا ۱۰ دقیقه صبر کنید تا تیک سبز بیاید.
۴) روی اجرای تمام‌شده بزنید. پایین صفحه در بخش Artifacts دو فایل هست:
      3eo-android-apk       ← داخلش app-release.apk است (همان فایل نصبی)
      KEYSTORE-KEEP-SAFE    ← فقط بار اول ساخته می‌شود؛ کلید امضای اپ است
۵) کلید امضا بسیار مهم است: اگر گم شود دیگر نمی‌توانید اپ را در بازار آپدیت کنید. پوشه‌ی KEYSTORE-KEEP-SAFE را جای امن (مثلاً ایمیل خودتان و فلش) نگه دارید.
   سپس در مخزن: Settings > Secrets and variables > Actions > New repository secret، دو مورد بسازید:
      KEYSTORE_BASE64    ← محتوای فایل KEYSTORE_BASE64.txt
      KEYSTORE_PASSWORD  ← محتوای فایل KEYSTORE_PASSWORD.txt
   از این به بعد هر ساخت با همان کلید امضا می‌شود.
۶) فایل app-release.apk را روی گوشی اندروید خودتان نصب و امتحان کنید (اجازه‌ی نصب از منبع ناشناس را بدهید). این‌ها را چک کنید: ورود با پیامک، یک تحلیل سایت، کشیدن صفحه به پایین برای تازه‌سازی، قطع اینترنت و دکمه‌ی «تلاش دوباره»، و اینکه هیچ جای اپ «خرید اعتبار» یا قیمت نیست.

بارگذاری در کافه‌بازار
----------------------
- پنل توسعه‌دهندگان بازار (developers.cafebazaar.ir) > افزودن برنامه > بارگذاری app-release.apk.
- نام: سئو (یا «سئو - ابزارهای سئو»)، آیکون ۵۱۲ در همین پوشه: store-icon-512.png، چند اسکرین‌شات از گوشی خودتان.
- نشانی حریم خصوصی: https://3eo.ir/privacy
- در توضیح و ردبندی سنی: اپ رایگان است و داخل آن خریدی نیست.
- نام بسته‌ی اپ ir.threeeo.app است و بعد از اولین انتشار قابل تغییر نیست.

نسخه‌های بعدی
-------------
- محتوای سایت با آپدیت سایت عوض می‌شود و نیازی به نسخه‌ی جدید اپ نیست.
- برای نسخه‌ی تازه‌ی اپ: در فایل app/build.gradle مقدار versionName را بالا ببرید (مثلاً 1.0.1)، دوباره Run workflow بزنید. شماره‌ی versionCode خودکار از شماره‌ی اجرا ساخته می‌شود.

توجه صادقانه
------------
این پروژه در محیطی ساخته شد که ابزار ساخت اندروید ندارد؛ پس خود ساخت APK آنجا اجرا نشد. اگر اجرای GitHub خطا داد، متن خطا (قسمت قرمز لاگ) را برایم بفرستید تا اصلاح کنم.
