اپ اندروید سئو (3eo.ir) برای کافه‌بازار و مایکت
================================================
این پروژه سایت را داخل یک اپ سبک باز می‌کند (با آیکون، کشیدن برای تازه‌سازی، صفحه‌ی «اینترنت قطع است»، اشتراک‌گذاری، دانلود فایل). داخل اپ هیچ چیزی برای خرید دیده نمی‌شود (قیمت‌ها، خرید اعتبار و درگاه پرداخت). کاربری که قبلاً در سایت اعتبار خریده همان اعتبار را در اپ مصرف می‌کند.

پیش از ساخت اپ: نسخه‌ی ۰٫۳۵٫۰ سایت را حتماً روی هاست آپدیت کنید (حالت اپ در آن است).

ساخت فایل APK با GitHub (ریپو عمومی است، پس کلید امضا فقط در Secrets می‌ماند)
----------------------------------------------------------------------
۱) کد همین ریپو آماده است. فایل‌های کلید امضا (keystore-3eo.zip) را از چت گرفته‌ای؛ آن را هرگز داخل ریپو آپلود نکن.
۲) ریپو > Settings > Secrets and variables > Actions > New repository secret، دو مورد بساز:
      KEYSTORE_BASE64    ← کل محتوای فایل KEYSTORE_BASE64.txt
      KEYSTORE_PASSWORD  ← کل محتوای فایل KEYSTORE_PASSWORD.txt
۳) تب Actions > «Build Android APK» > Run workflow. حدود ۵ تا ۱۰ دقیقه صبر کن.
۴) پایین صفحه‌ی اجرا، Artifact به نام 3eo-android-apk را دانلود کن؛ داخلش app-release.apk است.
۵) کلید امضا را جای امن نگه دار (اگر گم شود دیگر نمی‌توانی اپ را در بازار آپدیت کنی).
۶) APK را روی گوشی خودت نصب و امتحان کن: ورود با پیامک، یک تحلیل سایت، کشیدن به پایین برای تازه‌سازی، قطع اینترنت و «تلاش دوباره»، و نبودن هر چیز مربوط به خرید.

بارگذاری در کافه‌بازار
----------------------
- پنل توسعه‌دهندگان بازار (developers.cafebazaar.ir) > افزودن برنامه > بارگذاری app-release.apk.
- نام: سئو (یا «سئو - ابزارهای سئو»)، آیکون ۵۱۲ در همین پوشه: store-icon-512.png، چند اسکرین‌شات از گوشی خودتان.
- نشانی حریم خصوصی: https://3eo.ir/privacy
- در توضیح و ردبندی سنی: اپ رایگان است و داخل آن خریدی نیست.
- نام بسته‌ی اپ ir.threeeo.app است و بعد از اولین انتشار قابل تغییر نیست.

نسخه‌های بعدی
-------------
- محتوای سایت با آپدیت سایت عوض می‌شود و نیازی به نسخه‌ی جدید اپ نیست.
- برای نسخه‌ی تازه‌ی اپ: در فایل app/build.gradle مقدار versionName را بالا ببرید (مثلاً 1.0.1)، دوباره Run workflow بزنید. شماره‌ی versionCode خودکار از شماره‌ی اجرا ساخته می‌شود.

توجه صادقانه
------------
این پروژه در محیطی ساخته شد که ابزار ساخت اندروید ندارد؛ پس خود ساخت APK آنجا اجرا نشد. اگر اجرای GitHub خطا داد، متن خطا (قسمت قرمز لاگ) را برایم بفرستید تا اصلاح کنم.
